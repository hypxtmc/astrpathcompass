# 路径索引工作卡（astrpathcompass）

## 铁律：路径先行
涉及文件路径定位的任务，动手前必须先查 astrpathcompass 路径索引
（命令：`pathsearch`），按重要度返回候选路径，命中直接采用，
禁止凭记忆臆造绝对路径、禁止无索引直接重翻文档历史。

## 流程
1. `pathsearch [关键词]` → 返回按温度衰减排序的候选（近期命中者优先，7 天半衰期；code/db/misc 分类 + 命中次数 + 存活/失效标记 + `最近N前` 上下文锚）
2. 命中 → 用 test -f / ls 复核该路径当前存在，存在即采纳；`最近N前` 字段判断路径活跃度（找"最近在搞的文件"时优先选最近的）
3. 未命中 → 用 find / es_search / rg_search 常规检索，新路径会自动被捕获层收录进库
4. 定期巡检：`pathstatus` 看健康度与阈值，`pathsweep` 清死链并统计
5. 索引标记失效而文件实际存在 → 是布局变化，更新记录，勿盲删

## 限界
- 索引只记"路径在哪、多常用"，不记文件内容
- 死链记录保留供追查，不自动删除（"户口本"哲学）
- 捕获自动进行（含 shell 命令文本扫描），无需手动录入

## 命令速查
- `pathsearch` 检索索引（温度衰减排序，命中片段 ⟪高亮⟫，附最近命中时间锚）
- `pathstatus` 索引状态（记录数/存活/失效/捕获开关/建档阈值）
- `pathsweep` 手动巡检（检查失效路径）
- `pathexport <保存路径> [前缀]` 按前缀导出索引（无前缀=全量）
- `pathclean <前缀> [--yes]` 按前缀清理（默认预览，加 --yes 才执行）
