# 路径索引工作卡（astrpathcompass）

## 铁律：路径先行
涉及文件路径定位的任务，动手前必须先查 astrpathcompass 路径索引
（命令：`pathsearch`），按重要度返回候选路径，命中直接采用，
禁止凭记忆臆造绝对路径、禁止无索引直接重翻文档历史。

## 流程
1. `pathsearch [关键词]` → 返回候选路径（排序已按最近命中优先；带分类、命中次数、存活/失效标记、`最近N前` 活跃度提示）
2. 命中 → 用 test -f / ls 复核当前确实存在，再采纳；找"最近在搞的文件"优先看 `最近N前` 小的
3. 未命中 → 用 find / es_search / rg_search 常规检索（新路径会被自动收录，无需手动登记）
4. 索引标失效但文件实际在 → 是布局变化，更新记录，勿盲删

## 限界
- 索引只记"路径在哪、多常用"，不记文件内容；数据库在 SQLite，本卡不含路径清单
- 死链保留供追查，不自动删
- 捕获全自动（含命令文本扫描），无需手动录入

## 命令速查
- `pathsearch` 检索（命中片段 ⟪高亮⟫，附最近命中时间锚，无词=全部）
- `pathstatus` 索引状态（记录数/存活/失效/捕获开关/建档阈值）
- `pathsweep` 手动巡检（检查失效路径）
- `pathexport <保存路径> [前缀]` 按前缀导出索引
- `pathclean <前缀> [--yes]` 按前缀清理（默认预览）
- `pathsweep` 手动巡检（检查失效路径）
- `pathexport <保存路径> [前缀]` 按前缀导出索引（无前缀=全量）
- `pathclean <前缀> [--yes]` 按前缀清理（默认预览，加 --yes 才执行）
